# Robot-Ruka

Четырёхосевой манипулятор на Arduino: три вращательных сустава + вертикальная ось Z и серво-грейфер. Управление — по последовательному порту (115200) командами из внешней программы, позиции запоминаются и воспроизводятся.

## Железо

| Узел | Реализация |
|---|---|
| Суставы 1–3 | шаговые двигатели через драйверы STEP/DIR: (2,5), (3,6), (4,7) |
| Ось Z | шаговый двигатель: (12,13) |
| Грейфер | серво на `A0`, диапазон 600–2500 мкс |
| Концевики | `11`, `10`, `9`, `A3` (INPUT_PULLUP) |
| Контроллер | Arduino (Uno/Nano), прошивка `Robot-Ruka.ino` |

Библиотеки: [AccelStepper](https://www.airspayce.com/mikem/arduino/AccelStepper/) и `Servo` (обе ставятся через Library Manager).

## Прошивка

1. Открой `Robot-Ruka.ino` в Arduino IDE (папка проекта должна называться `Robot-Ruka`).
2. Установи библиотеки `AccelStepper` и `Servo`.
3. Выбери плату и порт, прошей.
4. При старте выполняется `homing()` по концевикам — убедись, что механике ничего не мешает.

Геометрия руки задаётся константами в начале скетча: `L1 = 228 мм`, `L2 = 136.5 мм`. Поправь под свою конструкцию.

## Протокол

Строка из чисел через запятую, например `0,0,90,90,90,100,180,800,1000`:

| Индекс | Значение |
|---|---|
| `data[0]` | сохранить текущую позу (1 — сохранить) |
| `data[1]` | воспроизвести записанную последовательность (1 — старт) |
| `data[2..4]` | углы суставов 1–3, градусы |
| `data[5]` | позиция оси Z |
| `data[6]` | грейфер, 0–180 |
| `data[7]` | скорость шаговиков |
| `data[8]` | ускорение |

Скорость и ускорение по умолчанию ограничены 4000 шаг/с и 2000 шаг/с².

## Ограничения

- Ходы суставов не ограничены программно, кроме концевиков — механический упор может сорвать шаг.
- Позиции хранятся в ОЗУ (массивы на 100 точек), при перезагрузке теряются.
- Калибровочные коэффициенты `angleToSteps` зашиты под конкретные редукторы: пересчитай их при другой механике.
